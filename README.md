LLM-powered research agent (LangGraph ReAct agent + Groq) that generates structured analyst briefs — fundamentals, valuation signal, news sentiment, risks, outlook — for any stock ticker from real-time financial data tools. Streaming FastAPI backend, Next.js/Tailwind chat UI.

**[GitHub Agent — Multi-Agent LangGraph System](https://github.com/kalpanaselvaa/github-agent)**
A coordinator-driven multi-agent system that automates GitHub project management: documentation, release notes, issue triage, and code review, each handled by a specialized subagent.

**QueryMind AI — Text-to-SQL Analytics Engine**
Production-style text-to-SQL pipeline (query classifier, schema linker, few-shot retriever, SQL generator, validator, executor) converting natural language into safe, validated SQL across a 7-table e-commerce schema — 72% execution accuracy on a 25-query benchmark, with a 5-panel Next.js admin UI and guardrails blocking destructive SQL.

**NovaWorks — AI HR Copilot**
Full-stack AI HR copilot (FastAPI, Next.js 14, GPT-4 Turbo, ChromaDB) for a simulated 1,000+ employee HRMS — RAG-based policy Q&A, a guarded read-only SQL agent, and tool-calling HR automations, with JWT-based RBAC, row/column-level security, and full audit logging.

**UrbanPulse — Smart City AI Analytics Suite**
End-to-end smart city analytics suite spanning traffic safety, infrastructure, and citizen services — an XGBoost/Random Forest accident-severity model, a CNN pothole detector, and a BERT-based NLP classifier that routes 311 service requests to the right department.
